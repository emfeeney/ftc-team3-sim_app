# Multi-Team Simulation & Configuration Guide

This simulator supports multiple FTC teams (e.g. Team 3, Team A, Team 2, Team 4, or any custom team).

---

## 1. How the Multi-Team Architecture Works

Each team has:
1. **Physical Robot Values (`configs/teams/team<ID>.properties`)**:
   - Chassis dimensions ($L \times W$)
   - Forward, strafe, and turn speeds
   - Coasting and traction acceleration limits
   - Motor port names and directions
2. **Autonomous Code (`TeamCode/` on `PVI-FTC/ftc-robot-framework`)**:
   - Their Java `@Autonomous` OpModes
   - Their Pedro Pathing bezier curves and sequences
3. **Recorded Replays (`web/vi_arena/recordings/`)**:
   - Self-contained 3D recordings (`auto-<OpMode>.json`) generated by running the headless FTC harness against the team's Java code and robot properties.

---

## 2. Adding a New Team to the Simulator

To add a new team permanently:

### Step A: Create the Team Configuration
1. Copy `configs/teams/team-template.properties` to `configs/teams/team<Number>.properties`.
2. Enter your team's robot name and hardware device names.
3. Fill in the measured or estimated values in the **Robot Facts** section (if you use Pedro Pathing, copy the numbers directly from your Pedro tuner OpModes: `maxAchievableForwardVelocity`, `naturalForwardDeceleration`, `quadraticBrakeCoefficients`, etc.).

### Step B: Sync TeamCode from Your Branch
Run:
```bash
bash web/sync-teamcode.sh <your-branch-name>
```
*(Default branch is `feature/team-3-setup`; other branches on `PVI-FTC/ftc-robot-framework` include `Team2-Robot-Code`, `Team_4_Branch`, `master`)*

### Step C: Activate Your Team and Generate 3D Recordings
```bash
# 1. Activate your team properties
bash configs/teams/switch-team.sh team<Number>

# 2. Run the headless simulator to record all autonomous runs
cd th_src
./gradlew test --tests "pvi.harness.GenerateTeam3AutonomousRecordingsTest" --rerun-tasks --no-daemon
./gradlew buildWebWrapper --no-daemon

# 3. Copy recordings to the WebGL arena folder
cp build/recordings/auto-*.json ../web/vi_arena/recordings/
cp build/recordings/auto-*.json ../web/build/recordings/
```

### Step D: View on the Website
- Push to GitHub (`git push origin main`). Render deploys the updated app automatically.
- Open the site: your team's runs will appear in the **Team** and **Autonomous** selectors!

---

## 3. Using the Web Simulator Without Touching Git (For Visiting Teams)
Any team can drop their own `.json` recording file directly into the WebGL viewer window (or click **Load JSON...**):
- The viewer parses the robot name and dimensions from the recording header.
- Automatically creates a team tab in the selector.
- Visualizes their exact robot size, trajectory, and telemetry in 3D.
